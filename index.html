01 — The mental model

Store by a name.
Find by a calculation.

A hash map stores pairs: a key that identifies something, and the value attached to it. The key is passed through a hash function to choose a bucket.

Think of a contact list

The key is the handle.

Instead of remembering where Rahul's number sits in a long list, ask for the entry by its key. The map takes care of locating the value.

03 — When keys overlap

Same bucket.
Different strategies.

A collision happens when two different keys produce the same index. It is normal, expected, and handled deliberately.

01 / Separate chaining

Each bucket points to a collection of entries. New keys with the same index join that collection.

bucket 3→10→17→24

Easy to understand; extra memory is used for links or collection nodes.

NOTE / A

Good hash function

Fast and deterministic, with keys spread evenly across buckets. Better distribution means fewer collisions.

NOTE / B

Load factor

How full the table is: entries divided by buckets. As it grows, implementations may resize and rehash.

NOTE / C

Not guaranteed O(1)

Average lookup is constant time with good hashing and controlled load. Heavy collisions can make operations much slower.

04 — Performance snapshot

Fast on average.
Not magic.

The familiar O(1) headline describes average-case behavior, not a promise for every input or every implementation.

Space complexity

O(n)

Space grows with the number of stored entries. The table also maintains bucket capacity, and some implementations allocate extra room to keep lookups fast.

n = number of key–value pairs
05 — Out in the world

Quietly everywhere.

Hash maps are a practical building block in software. These are a few familiar places where key-based fast access is useful.

🌐

Caching

Reuse a result by looking it up with a request or resource key.

▤

Database indexing

Hash-based indexes can help locate records for equality lookups.

▥

Frequency counts

Count words or events by storing each item as a key.

⌘

Symbol tables

Compilers use name-to-information mappings for identifiers.
